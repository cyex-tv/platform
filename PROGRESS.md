## What is live

- Platform monorepo on `main`: Rust API (`apps/api`: GraphQL at `/v1/gql`, REST for uploads and webhooks), worker, events (live updates), shared crates (`crates/*`), SvelteKit website (`apps/web`) and the dev mock (`apps/web/dev/mock-api.mjs`).
- Accounts and sign-in (Twitch, Kick), cookie sessions, console tokens, app sign-in for cyex deck, roles with allow, inherit and deny per permission, restrictions and the audit log.
- Emotes: upload pipeline and review gate, sizes up to 4x (at most 128 px tall), flags (overlaying, private; unlisted is staff's), no NSFW, transfers that only the owner starts and the receiver accepts.
- Sets and editors: every set public, capacity per role, account editors with emote permissions, channels and the set menu.
- Search and browse: emote search with trending, header quick search, person filters with top suggestions.
- Profiles: activity, notifications, Account and Editors tabs, entitlement graph for staff.
- Cosmetics (badges and paints, studio), the shop, redeem codes and Paddle checkout, announcements.
- Website in the Workspace / Inspector design, full width, dark and light.
- Docs pages, help, changelog, and the developers guide (GraphQL reference from the committed schema).
